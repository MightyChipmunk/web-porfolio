    고퀄리티 비주얼 구현

    마케팅 퍼포먼스 극대화

    URP/HDRP 파이프라인 및 포스트 프로세싱을 활용하여 높은 수준의 시각적 연출을 구현하고 마케팅 퍼포먼스를 극대화했습니다.

    Technical Challenges

    01
    Camera

    카메라 연출 시스템 구축

    Problem
    • 프로젝트마다 다양한 카메라 연출이 요구되었으나, 매번 새로 구현해야 하여 제작 시간이 길어졌습니다.
    • 연출 구도의 즉각적인 전환이 어려워 반복적인 수정 작업이 필요했습니다.
    Solution
    • 다양한 연출 구도를 프리셋화하고 즉각적인 전환이 가능하도록 모듈 형태의 카메라 제어 시스템을 설계했습니다.
    Result
    • 카메라 연출 작업 시간이 크게 단축되었고, 프리셋 기반으로 일관된 품질의 영상을 빠르게 제작할 수 있게 되었습니다.
    02
    Graphics

    그래픽 파이프라인 고도화

    Problem
    • 프로젝트 컨셉에 따라 요구되는 비주얼 스타일이 다양했으며, 단일 렌더 파이프라인으로는 최적의 품질을 달성하기 어려웠습니다.
    Solution
    • 프로젝트 컨셉에 맞춰 URP/HDRP를 선택적으로 운용하며 최적의 포스트 프로세싱 환경을 설정했습니다.
    Result
    • 각 프로젝트에 최적화된 비주얼 품질을 구현하여, 마케팅 영상의 시각적 임팩트를 극대화할 수 있었습니다.
    03
    Workflow

    워크플로우 가속화 - 연출 모듈화 및 프리셋 시스템

    Problem
    • 신규 프로젝트 투입 시 연출 환경을 처음부터 세팅해야 하여 초기 작업 시간이 과도하게 소요되었습니다.
    • 비개발자가 연출을 수정하려면 개발자의 직접적인 지원이 필요한 구조였습니다.
    Solution
    • 연출 기능을 모듈화하여 신규 프로젝트 투입 시 즉시 촬영 가능한 프리셋 시스템을 구축했습니다.
    • 비개발자 전용 커스텀 에디터를 제작하여 독립적으로 연출 파라미터를 조정할 수 있도록 했습니다.
    Result
    • 신규 프로젝트의 초기 세팅 시간을 대폭 단축하고, 비개발자도 독립적으로 연출을 수정할 수 있게 되어 전체 제작 주기가 크게 개선되었습니다.
