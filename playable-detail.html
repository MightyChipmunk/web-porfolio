Key Achievements

마케팅 효율 극대화

CPI 절감 → 글로벌 런칭 결정

높은 CPI로 출시가 불투명했던 프로젝트에 플레이어블 광고를 도입하여 CPI를 크게 낮추고 글로벌 런칭 결정에 핵심적으로 기여했습니다.

    유저 유입 및 전환율 개선

    신규 다운로드 10% 이상 상향

    라이브 서비스 중인 게임의 마케팅 파이프라인에 투입되어, 일주일 만에 신규 다운로드 수를 10% 이상 상향시키는 성과를 달성했습니다.

    Technical Challenges

    01 Architecture

    설계 및 생산성 - 디자인 패턴 기반 핵심 시스템 모듈화

    Problem
    • 프로젝트마다 유사한 시스템을 반복 구현해야 했고, 빠른 개발 주기 속에서 코드가 특정 프로젝트에 강하게 결합되어 재사용이 어려웠습니다.
    • 기획 변경 시 수정 범위가 넓어지는 문제가 빈번했습니다.
    Solution
    • 반복 사용되는 핵심 시스템을 MVC/상태/전략/명령 등의 디자인 패턴을 적용하여 모듈 간 의존성을 최소화한 재사용 가능한 패키지로 분리했습니다.
    Result
    • 신규 프로젝트의 초기 세팅 시간을 대폭 단축하고, 기획 변경 시 영향 범위를 최소화할 수 있었습니다.
    • 검증된 모듈을 다른 프로젝트에 빠르게 이식할 수 있게 되어 전체 개발 주기가 크게 개선되었습니다.
    03 Performance

    성능 및 그래픽 최적화 - 저사양 웹 환경에서의 렌더링과 프레임 확보

    Problem
    • 플레이어블 광고는 모바일 웹뷰에서 구동되기 때문에 네이티브 앱 대비 성능이 크게 제한됩니다.
    • 다수의 오브젝트가 동시에 활성화되는 장르에서 프레임 드롭이 심각했고, 원본 게임의 셰이더가 WebGL 환경에서 호환되지 않거나 렌더링 부하가 과도한 문제도 빈번했습니다.
    Solution
    • 그리드 기반 공간 분할로 충돌 검사 범위를 최소화하고, 게임 오브젝트와 파티클을 풀링하여 연산량 및 GC를 억제했습니다.
    • 유니티의 물리 엔진 대신 미리 베이크한 애니메이션을 사용하며 연산 부하를 줄였습니다.
    • AI를 활용해 복잡한 셰이더를 분석하여 WebGL 호환 경량 셰이더로 변환하여 불필요한 연산을 제거했습니다.
    Result
    • 저사양 모바일 웹 환경에서도 원본에 가까운 비주얼 품질과 안정적인 프레임을 동시에 확보하여, 유저가 끊김 없이 게임을 체험할 수 있는 환경을 구축했습니다.
    05 Optimization

    빌드 용량 최적화 - 4MB 미만 용량 구현

    Problem
    • 플레이어블 광고는 대부분의 광고 네트워크에서 4MB 이하의 용량 제한이 있습니다.
    • 3D 게임의 텍스처, 메시, 애니메이션 등의 에셋을 포함하면 이 제한을 쉽게 초과하게 되어, 품질과 용량 사이의 균형을 맞추는 것이 핵심 과제였습니다.
    Solution
    • 컬러맵 텍스처 기법을 활용하여 다수의 텍스처를 하나의 팔레트 텍스처로 통합하고, 메시 데이터를 최적화했습니다.
    • 불필요한 애니메이션 키프레임을 제거하는 툴을 개발하여 애니메이션의 용량을 최적화하였습니다.
    Result
    • 시각적 품질을 유지하면서 4MB 미만의 빌드 용량을 안정적으로 달성하여, 모든 주요 광고 네트워크의 요구 사항을 충족시켰습니다.
    06 Teamwork

    연출/로직 모듈화 및 배포 - 팀 전체 생산성 향상

    Problem
    • 마케팅 성과가 높았던 특정 연출 기법이나 게임 로직이 개별 프로젝트에 종속되어 있어, 다른 팀원이 유사한 연출을 구현하려면 처음부터 다시 개발해야 하는 비효율이 발생했습니다.
    Solution
    • 성과가 검증된 연출과 로직을 프로젝트에서 분리하여 독립적인 모듈로 재설계했습니다.
    • 각 모듈에 사용 가이드와 커스터마이징 포인트를 명시하고, 팀 내 패키지로 배포하여 누구나 쉽게 적용할 수 있도록 했습니다.
    Result
    • 팀 전체의 개발 생산성이 향상되었으며, 검증된 연출을 빠르게 적용함으로써 신규 프로젝트의 초기 마케팅 성과를 높이는 데 기여했습니다.
